# AMBURSA

Private robotics, AI, and custom PC build project.

## What this repo contains

- Static site pages for the main site, projects, builds, and dashboard
- Shared frontend styles and vanilla JavaScript behavior
- A small Node.js/Express server for local development and API routes
- Inventory and order data used by the builds/dashboard experience

## Local run

```bash
npm start
```

The site runs at `http://localhost:3000`.

## Main pages

- `index.html` - homepage
- `projects.html` - project showcase
- `builds.html` - PC builds storefront and configurator
- `dashboard.html` - internal inventory dashboard
