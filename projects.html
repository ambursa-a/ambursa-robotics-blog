Deterministic BMS Stack (High-Voltage + FreeRTOS)

Custom C++ firmware built on FreeRTOS for managing cell balancing, high-voltage contactor logic, and isolation fault detection in custom EV battery packs. Built to run on resource-constrained embedded systems while maintaining real-time safety constraints. 

// High-Voltage Isolation & Fault Task
void isolation_task(void* arg) {
  BmsState state;
  while (1) {
    float iso_res = read_iso_resistance();
    float pack_v  = read_pack_voltage();

    if (iso_res < MIN_OHMS_VOLT * pack_v) {
      trigger_hv_fault(FAULT_ISO_LOSS);
      open_contactors();
    }

    xQueueSend(
      telemetry_q, &state, 0
    );
    vTaskDelayUntil(
      &last_wake, pdMS_TO_TICKS(50)
    );
  }
}
